# Code of conduct

This project welcomes technical disagreement and expects respectful,
evidence-based collaboration.

Participants must not harass, threaten, demean, discriminate against, or expose
private information about another person. Feedback should address the work,
include enough context to be actionable, and respect the project's privacy,
licensing, and authorized-use boundaries.

Maintainers may edit, hide, lock, or remove contributions that violate these
expectations and may restrict participation when necessary. Use GitHub's content
reporting tools for urgent platform-safety concerns. Do not use a public conduct
report to disclose a software vulnerability; follow [`SECURITY.md`](SECURITY.md)
instead.
